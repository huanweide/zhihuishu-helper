## 三、播放器控制元素（legacy/wisdom 通用）

| 功能 | 选择器 | 操作 |
|------|--------|------|
| 视频元素 | `video` | `play()` / `pause()` / `currentTime` |
| 播放按钮 | `.playButton` | `click()` |
| 音量盒 | `.volumeBox` | 检测 `.passVolume` 宽度判断是否静音 |
| 音量图标 | `.volumeIcon` | `click()` 切换静音 |
| 倍速盒 | `.speedBox` | 读 `style` 判断当前倍速 |
| 1.5 倍速 | `.speedTab15` | `click()` |
| 倍速列表项 | `.speedList [rate="1.5"]` | `click()`（注意 1.0 与 1 的兼容） |
| 清晰度盒 | `.definiBox` | |
| 流畅画质 | `.line1bq` | `click()` |
| 高清画质 | `.line1gq` | `click()` |
| 进度条 | `.current_play .progressbar` | 宽度比 = 完成度 |
| 进度条底槽 | `.current_play .progressbar_box` | |
| 控制条 | `.controlsBar` | 默认可能 `display:none`，需先置 `block` |
| 清晰度列表 | `.definiLines` | 同上 |
| 夜间模式按钮 | `.Patternbtn-div` | `click()` |

### 3.1 重要：控制条隐藏问题

部分版本下 `.controlsBar` / `.definiLines` / `.speedList` 默认 `display:none`，
直接 `click()` 无效。**必须先把父容器 `display` 设为 `block`**：

```js
const controlsBar = document.querySelector('.controlsBar');
const sl = document.querySelector('.speedList');
if (controlsBar && sl) {
  controlsBar.style.display = 'block';
  sl.style.display = 'block';
  document.querySelector('.speedList [rate="1.5"]')?.click();
}
```

## 四、课中弹题（video 内弹窗测验）

```html
<div id="playTopic-dialog">
  <div class="el-pager">
    <span class="number active">1</span>
    <span class="number">2</span>
  </div>
  <ul>
    <li class="topic-item">选项A</li>
    <li class="topic-item">选项B</li>
  </ul>
  <div class="topic">
    <div class="radio">
      <ul>
        <li>选项按钮1</li>
        <li>选项按钮2</li>
      </ul>
    </div>
  </div>
  <div class="close-btn"></div>
  <div class="btn"></div>
</div>
```

**处理流程**：
1. 轮询检测 `#playTopic-dialog` 是否可见（每 2-3 秒）
2. 遍历 `.el-pager .number`，逐个切换分页
3. 每个分页取 `ul .topic-item` 的文本作为选项列表
4. 取题干文本（需实测确认选择器，可能为 `.topic-title`）
5. 调答题引擎得答案 → 点击 `ul > li:nth-child(N)`
6. 全部答完后点 `.close-btn` 或 `.btn` 关闭

**注意**：`.topic-title` 也是**遮挡层**（blocking overlay），弹题出现时视频会被遮挡/暂停。

## 七、反自动化措施（已识别）

| 措施 | 表现 | 应对 |
|------|------|------|
| **滑块验证** | `yidun_popup` / `yidun_modal` / `yidun_jigsaw` / `yidun_bg-img` | 检测到即暂停脚本，弹窗提示用户手动过 |
| **腾讯验证码** | `[id^='tcaptcha_transform']` | 同上 |
| **弹题遮挡** | `.topic-title` 可见时视频被挡 | 检测到暂停视频，处理完再恢复 |
| **自定义弹窗** | `.ss2077-custom-dialog` | 关闭后恢复 |
| **进度延迟上报** | 视频放完但平台只记录 80% | 回退到平台记录点重播，最多重试 2 次 |
| **焦点检测** | 窗口失焦/最小化可能卡死 | 提示用户保持窗口可见（可缩小不可最小化） |
| **脚本冲突检测** | 装多个脚本导致选项点不上 | 提示不要与其他脚本混用 |
