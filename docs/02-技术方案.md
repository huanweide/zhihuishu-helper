## 一、总体架构

### 1.1 形态选择：为什么用油猴脚本

| 方案 | 部署 | 断点续播 | AI 答题 | 跨域 | 反检测 | 结论 |
|------|------|----------|---------|------|--------|------|
| Chrome 扩展 | 中（需开发者模式加载） | 好 | 好（有后台脚本） | 好（`host_permissions`） | 中 | 备选 |
| **油猴脚本** | **低（装 Tampermonkey 即用）** | **好** | **好（GM_xmlhttpRequest 可跨域）** | **好** | 中 | **主选** |
| Playwright | 高（Python+内核） | 好 | 好 | 无限制 | 强 | 兜底 |

**决策：主选油猴脚本。**
关键理由：`GM_xmlhttpRequest` 可以绕过 CORS 调用 LLM API 和本地题库服务，
既保留了零部署的优势，又不受跨域限制。

## 二、F1 自动播放

### 2.1 主循环（每 2 秒）

```js
async function playbackLoop() {
  const video = document.querySelector('video');
  if (!video) return;

  // 守卫1：验证码弹窗 → 暂停视频，等用户处理
  if (hasVisible('.yidun_popup, .yidun_modal, [id^="tcaptcha_transform"]')) {
    if (!video.paused) video.pause();
    await waitUntilHidden('.yidun_popup, .yidun_modal, [id^="tcaptcha_transform"]');
    return;
  }

  // 守卫2：弹题遮挡 → 暂停视频，交给答题模块
  if (hasVisible('.topic-title, #playTopic-dialog')) {
    if (!video.paused) video.pause();
    await handleQuestionDialog();
    return;
  }

  // 守卫3：非视频节点（文档/PPT）→ 略过
  if (!isVideoNode()) { nextLesson(); return; }

  // 正常保活
  if (video.paused && !video.ended && video.currentTime > 0) {
    video.muted = true;                       // 必须静音才能绕过 autoplay policy
    video.play().catch(() => {});
  }

  // 结束 → 下一节
  if (video.ended || atEnd(video)) {
    await sleep(3000);                        // 等平台上报进度
    const p = await getCatalogProgress();
    if (p >= 100) nextLesson();
    else retryFrom(p);                        // 进度没满，回退重播
  }
}
```

### 2.2 "结束"判定的坑

不能只看 `video.ended`，因为：
- 平台可能在末尾 2 秒上报进度，此时 `ended` 还是 `false`
- 有些视频 `duration` 是 `NaN`（未加载完）

**判定式**：
```js
function atEnd(v) {
  return Number.isFinite(v.duration) && v.duration > 0
    && v.currentTime / v.duration >= 0.995;
}
```

### 2.3 进度不同步的回退重试（借鉴 Autovisor）

```
视频放完 → 查平台进度 catalogProgress
  ├─ >= 100% → 下一节
  └─ < 100% → 视频 currentTime 设到 进度对应时间点 → 重播
              最多重试 2 次，超过就报警跳过
```

对应时间点换算：
```js
const expected = (catalogProgress / 100) * video.duration;
video.currentTime = expected;
```

### 2.4 倍速与静音

```js
// 倍速：优先用 video.playbackRate（直接生效，不依赖 UI）
video.playbackRate = CONFIG.speed;          // 建议 ≤ 1.8，超过可能不上报进度

// 同时同步 UI（避免平台检测到播放器倍速与 UI 不一致）
document.querySelector('.speedList [rate="1.5"]')?.click();
document.querySelector('.speedBox span') && 
  (document.querySelector('.speedBox span').innerText = 'X ' + CONFIG.speed);

// 静音：video.volume = 0 更保险（muted 属性可能被平台重置）
video.volume = 0;
document.querySelector('.volumeBox')?.classList.add('volumeNone');
```

> **重要**：倍速上限建议 **1.8**。实测 2x 以上平台可能不记录进度。

## 三、F2 断点续播

### 3.1 存储结构

```js
// key: 'zhs-helper-resume'
{
  "courses": {
    "4e5f5b5c4c5b4859454a585958435f475a": {   // recruitAndCourseId
      "lessonKey": "第一章|1.1 课程导论",
      "time": 372.5,
      "duration": 1200,
      "updatedAt": 1758114459000
    }
  }
}
```

### 3.2 写入时机（节流：5 秒一次）

```js
video.addEventListener('timeupdate', throttle(() => {
  if (!video.paused && video.currentTime > 5) {
    Resume.save(courseId, lessonKey, video.currentTime, video.duration);
  }
}, 5000));
```

### 3.3 恢复流程

```
页面加载完成
 ↓
读 storage → 取当前 courseId 的记录
 ↓
有记录？
 ├─ 否 → 正常从头开始
 └─ 是 → 定位 lessonKey 对应的章节条目
          ├─ 未找到（无此课）→ 忽略，从头开始
          └─ 找到 → click() 切到该课时
                     ↓
                   等 video 触发 loadedmetadata
                     ↓
                   video.currentTime = time - 2   （回退 2 秒保险）
                     ↓
                   play()
```

### 3.4 跨页面持久化的坑

智慧树是 **SPA + 可能的 iframe 嵌套**，要注意：

| 坑 | 现象 | 解决 |
|----|------|------|
| iframe 隔离 | 在 iframe 里写 localStorage，主页面读不到 | 统一写 `window.top.localStorage`（同源才行） |
| SPA 路由切换 | 不触发 `load` 事件 | 用 `MutationObserver` 监听 DOM 变化重新绑定 |
| 切课刷新 | 记录丢失 | `GM_setValue` 比 localStorage 更稳（跨域共享） |
| 课程 ID 变化 | 记录串课 | 用 `recruitAndCourseId` 作 key，不要用课程名 |

**推荐用 `GM_setValue` / `GM_getValue`**（Tampermonkey 提供），
不受同源限制，且所有页面共享。

### 3.5 冷启动恢复

用户可能**直接关掉浏览器再打开**。恢复依赖：
- `GM_setValue` 持久化到磁盘（Tampermonkey 默认行为）
- 下次访问同域名时读出来 → 自动跳到该课

**边界处理**：
- 记录超过 **7 天** → 视为过期，清除
- 记录时间点 > `duration - 10` → 视为已完成，从头开始

## 四、F3 AI 自动答题

### 4.1 双通道决策流

```
采集到题目 {title, options[], type}
        ↓
   ┌────────────────────┐
   │ 通道A：题库搜索      │  ← 优先，快且准，免费
   │ POST /adapter-service/search
   └────────┬───────────┘
            │ 命中？
      ┌─────┴─────┐
      是          否
      │           │
   直接回填    ┌──────────────────┐
              │ 通道B：LLM 生成    │
              │ N 次生成 → 投票    │
              └────────┬─────────┘
                       │
                   答案回填 + 校验
```

### 4.2 通道 A：题库（TikuAdapter）

**部署**：本地运行 TikuAdapter（[DokiDoki1103/tikuAdapter](https://github.com/DokiDoki1103/tikuAdapter)）
- 下载 Release 可执行文件，或 Docker 起 `:8060`
- 免费源：`icodef`（icodef 题库）、`buguake`（不挂科/百度教育）

**协议**：
```
POST http://localhost:8060/adapter-service/search
Content-Type: application/json

{
  "question": "违反安全保障义务责任属于（）",
  "options": ["公平责任", "特殊侵权责任", "过错推定责任", "连带责任"],
  "type": 1        // 0单选 1多选 2填空 3判断 4问答
}

→ 响应（标准格式）
{
  "code": 200,
  "data": {
    "answers": ["B"],
    "from": "icodef"
  }
}
```

**跨域**：油猴下用 `GM_xmlhttpRequest` 请求 `localhost:8060`，无 CORS 问题。

### 4.3 通道 B：LLM 生成 + 投票

**为什么投票**：LLM 有随机性（`temperature > 0`），
单次输出可能是错的；同一题问 N 次取众数，正确率显著提升。

**Prompt 模板**（来自 king-wang123 项目，实测有效，稍作强化）：

```
请仔细阅读以下题目并思考分析，根据题目类型，严格按照以下要求作答：

选择题（单选）：从选项中选择一个正确答案，仅输出该选项（A、B、C或D），不提供任何额外解释。
选择题（多选）：选择所有正确选项，仅输出所有正确选项的字母，用','分隔（如A,C），按字母顺序排列，不提供任何额外解释。
判断题：仅输出 "对" 或 "错"，不提供任何额外解释。

题目：
{题干}

选项：
A. xxx
B. xxx
C. xxx
D. xxx

你的答案：
```

**投票实现**：
```js
async function vote(title, options, type, n = 3) {
  const votes = {};
  for (let i = 0; i < n; i++) {
    const ans = normalize(await llm(title, options, type));
    votes[ans] = (votes[ans] || 0) + 1;
    if (votes[ans] >= 2) return ans;        // 提前收敛
  }
  return Object.entries(votes).sort((a, b) => b[1] - a[1])[0][0];
}
```

**答案归一化**（关键：模型输出常有噪音）：
```js
function normalize(raw) {
  const s = String(raw).trim().toUpperCase();
  // 多选：提取所有 A-D 字母
  const letters = s.match(/[A-D]/g);
  if (letters && s.replace(/[\s,A-D、,，]/g, '') === '') {
    return [...new Set(letters)].sort().join(',');   // 去重 + 排序
  }
  if (/对|正确|T(RUE)?/.test(s))   return '对';
  if (/错|错误|F(ALSE)?/.test(s))  return '错';
  return s;
}
```

### 4.4 图片题处理

部分题目只有图片没有文本（智慧树选项用 `<img>` 而非文字）。

**方案**：
1. 优先读 `img.src`（若为 `data-src` 则先赋值到 `src` 让浏览器加载）
2. 用 `html2canvas` 截取题目区域 → base64
3. 调用**多模态 LLM**（如支持 vision 的接口）直接识图答题
4. 或本地 OCR（`tesseract.js`，纯前端可用）

```js
if (img.dataset.src) img.src = img.dataset.src;   // 智慧树特性：未显示时在 data-src
```

### 4.5 答案回填（三种控件）

```js
// 1. 单/多选（element-ui 风格）
const input = option.querySelector(
  'input[type=radio],input[type=checkbox],' +
  '.el-radio__input:not(.is-checked),.el-checkbox__input:not(.is-checked)'
);
if (input && !input.checked) option.click();

// 2. 判断题（按文本匹配"对"/"错"）
for (const el of options) {
  if (el.innerText.trim().includes(answer)) { el.click(); break; }
}

// 3. 填空题
const ta = option.querySelector('textarea, input[type=text]');
if (ta) {
  ta.value = answer;
  ta.dispatchEvent(new Event('input', { bubbles: true }));
  ta.dispatchEvent(new Event('change', { bubbles: true }));
}
```

**必做校验**：
```js
// 点击后 200ms 检查是否真的选上（智慧树可能因脚本冲突点不上）
await sleep(200);
if (!option.querySelector('input')?.checked) {
  log('选项未选中，重试或换点击方式');
  option.querySelector('.el-radio__inner')?.click();   // 退而求其次点内层
}
```

### 4.6 课中弹题（#playTopic-dialog）特殊处理

```js
async function handleQuestionDialog() {
  const dlg = document.querySelector('#playTopic-dialog');
  if (!dlg || !isVisible(dlg)) return;

  const pages = dlg.querySelectorAll('.el-pager .number');
  for (const page of pages) {
    if (!page.classList.contains('active')) {
      page.click();
      await sleep(500);
    }
    const options = [...dlg.querySelectorAll('ul .topic-item')];
    if (!options.length) continue;

    const title = dlg.querySelector('.topic-title, .topic-content')?.innerText || '';
    const answer = await solve({ title, options: options.map(o => o.innerText), type: guessType(options) });

    // 点击对应序号的选项按钮
    const idx = toIndex(answer);           // 'B' → 1
    const btn = dlg.querySelector(`.topic .radio ul > li:nth-child(${idx + 1})`);
    btn?.click();
    await sleep(800);
  }

  await sleep(500);
  dlg.querySelector('.close-btn, .btn')?.click();
}
```

**注意**：`#playTopic-dialog` 内是 **iframe** 的情况也存在
（`tmDialog_iframe`），需要 `iframe.contentDocument` 访问内部 DOM。

## 八、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 平台改版 | 选择器失效 | 适配层多版本并存 + 自动探测 + 失效告警 |
| 账号风控 | 学时作废/封号 | 随机延迟、倍速限制、不要 7×24 挂 |
| 题库收费 | 免费源不够 | 优先免费源（icodef/不挂科），LLM 兜底 |
| LLM 幻觉 | 答错 | 多次投票 + 题库交叉验证 |
| 脚本冲突 | 页面卡死 | 启动时检测其他脚本并告警 |
| 验证码 | 卡住 | 检测到即暂停 + 提示用户，不硬闯 |
