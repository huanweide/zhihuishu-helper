# M2 使用说明（自动播放 + 断点续播）

> 版本 v0.1.0 · 2026-09-17
> 当前已实现：**F1 自动播放** + **F2 断点续播**
> 未实现：F3 AI 答题（M4/M5）

## 一、安装（3 步）

### 1. 装油猴扩展
浏览器装 **Tampermonkey（篡改猴）**：
- Chrome：扩展商店搜 "Tampermonkey"
- Edge：扩展商店搜 "Tampermonkey"

### 2. 导入脚本
打开 Tampermonkey 面板 → **添加新脚本** → 全选删除模板内容 →
把 `dist/zhihuishu-helper.user.js` 的**全部内容**粘进去 → `Ctrl+S` 保存。

或者：把 `dist/zhihuishu-helper.user.js` 直接**拖进浏览器窗口**，
Tampermonkey 会自动识别并弹出安装页。

### 3. 验证
打开智慧树播放页，按 `F12` 看 Console，应该看到：

```
[智慧树助手] 助手已注入 v0.1.0
[智慧树助手] === 初始化开始 ===
[智慧树助手] 页面版本识别为：智慧版共享课 (wisdom)
[智慧树助手] 课程 ID：4e5f5b5c4c5b4859454a585958435f475a
[智慧树助手] 视频元素已就绪，时长 1200s
[智慧树助手] 主循环已启动
```

右下角会出现**蓝色圆形按钮「智」**，点开是控制面板。

**设置页可切换**：

| 开关 | 默认 | 说明 |
|------|------|------|
| 自动播放 | 开 | 防暂停 + 自动恢复 |
| 自动下一节 | 开 | 结束自动切下一课 |
| 静音 | 开 | 必须静音才能绕过自动播放策略 |
| 断点续播 | 开 | 记录进度，重开自动续上 |
| AI 自动答题 | **关** | M4/M5 才实现 |
| 倍速 | 1.5x | 滑块 1.0 ~ 1.8（**硬上限 1.8**） |
| 调试日志 | 开 | Console 打印详细信息 |

## 四、断点续播怎么工作

### 记录时机
- 播放中每 **5 秒**存一次（节流）
- **暂停时**立刻存一次（防关页面丢进度）
- 前 5 秒不存（没什么意义）
- 距结尾 10 秒内不存（下次应从下一课开始）

### 存储位置
- 优先 `GM_setValue`（Tampermonkey 提供，**持久化到磁盘，跨 iframe/页面共享**）
- 无 GM 环境降级 `localStorage`

存储结构：
```json
{
  "courses": {
    "4e5f5b5c4c5b4859454a585958435f475a": {
      "lessonKey": "1.1 课程导论",
      "time": 372.5,
      "duration": 1200,
      "updatedAt": 1758114459000,
      "siteVersion": "wisdom"
    }
  }
}
```

### 恢复时机
页面加载 → 读记录 → 定位课时 → 切过去 → 等元数据 → `currentTime` 设到 `记录点 - 2秒`（回退保险）→ 播放

### 边界处理
| 情况 | 行为 |
|------|------|
| 记录超过 7 天 | 视为过期，清除，从头开始 |
| 记录中的课时已不存在 | 清除记录，从头开始 |
| 视频时长变了（换清晰度） | 按比例换算恢复点 |
| 记录点接近结尾 | 保存时就不记 |

## 五、三个必须知道的坑

### 1. 倍速别超过 1.8
代码里已硬夹逼（`Math.min(Math.max(speed, 0.5), 1.8)`），
因为实测 2x 以上平台**不记录学习进度**。

### 2. 不要最小化浏览器
浏览器会节流不可见标签页的定时器（Chrome 最低降到 1 次/分钟），
导致脚本卡死。**可以缩小窗口，但不能最小化。**

### 3. 不要和其他刷课脚本一起用
多个脚本操作同一批 DOM 会互相干扰，导致选项点不上、页面卡死。
装之前先禁用其他同类脚本。

## 六、已知限制（v0.1）

| 限制 | 影响 | 计划 |
|------|------|------|
| AI 答题未实现 | 弹题时会暂停并提示 | M4/M5 |
| 验证码需手动 | 检测到易盾滑块会暂停 | 设计如此（不做自动过，风险高） |
| 仅实测 4 套页面结构 | 若平台新增第 6 套可能失效 | 适配层已留扩展点 |
| 无习惯分功能 | 定时学习打卡未做 | 后续可选 |

## 七、出问题怎么排查

1. **Console 看日志**：所有动作都有 `[智慧树助手]` 前缀
2. **面板 → 日志页**：最近 80 条
3. **`zhs.logs()` 全量导出**
4. 如果页面版本显示 `unknown` → 平台改版了，把日志发出来，我加适配
5. 遇到问题先看 `docs/03-踩坑记录.md`，17 个坑基本覆盖常见情况
