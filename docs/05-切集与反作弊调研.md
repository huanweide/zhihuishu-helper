> 侦察方式：playwright-cli 0.1.22 操控**已登录态 Edge 真机**（本地持久 profile，session `zhs`），真实点击 + 运行时 hook 取证

> 本篇回答三个问题：① 人类到底怎么切集 ② 为什么脚本"下一集跳转"被检测/不支持 ③ 没看完的列表怎么续看

## 〇、结论速览（一句话）

1. **人类切集 = 点左侧目录里小节的"标题文字"**（`span.catalogue_title`）→ **页内换源**，URL 不变、不跳走。
2. **"脚本跳转不支持"的根因 = 平台用「异常 seek/拖进度」当反作弊信号**：脚本想靠拖进度条跳到结尾来 advance 下一集，就触发**腾讯 Turing 滑块拼图验证码**，脚本解不了 → 卡死。而**点标题切集不 seek，不会触发验证码**。
3. **续看 = 运行时动态扫描 `.time_icofinish`（平台已记完成）来跳过已完结；未完结项点标题切过去，会从断点续播（paused），需手动 `play()`。**

## 一、人类切集的真实方式（已实测确认）

### 1.1 目录 DOM 结构

章节列表是 legacy 版，每个小节是一个 `li.clearfix.video`：

```html
<li class="clearfix video current_play">
  <span class="catalogue_title3 fl cataloguediv-l"><b class="pl5 hour">1.1</b></span>
  <div class="fl cataloguediv-c">
    <span class="catalogue_title" title="向量及其线性运算">向量及其线性运算</span>
    <div>
      <b class="time_ico_half fl"></b>      <!-- 所有项都有，只是进度底条 -->
      <b class="fl time_icofinish"></b>      <!-- 仅"已完成"项有，是完成标志 -->
      <span class="time fl">00:09:06</span>
    </div>
  </div>
  <em class="Sectionmark-em"></em>
</li>
```

- 列表容器：`UL.list` → `li.clearfix.video`
- **整条祖先链没有 `<a>` 链接**（`closest('a')` 返回 NONE）。所以"跳门户"不是因为点了 `<a>`，而是 `li`/内部元素的 **Vue `@click` 处理器**在某些条件下主动 `location.href` 跳转（见第三节）。
- 真实可点目标 = **`span.catalogue_title`**（小节标题文字）。人类点的就是这个。

### 1.2 实测：点标题 → 页内切集（不跳走）

派发真实鼠标事件（mousedown+mouseup+click，带坐标）到 `span.catalogue_title`：

| 动作 | URL | video src | current_play |
|------|-----|-----------|--------------|
| 点 2.25 标题前 | studyvideoh5… | 1.1 的 mp4（ct=546） | 1.1 |
| 点 2.25 标题后 | **不变** | 换成 2.25 的 mp4（ct=474/622，断点续播） | **2.25** |
| 点 4.4 标题后 | **不变** | 换成 4.4 的 mp4（ct=28/515） | **4.4** |

→ **确认：点标题 = 页内换 video 源，URL 始终 `studyvideoh5`，无任何跳转。**

### 1.3 切集触发的真实 API 流（抓包确认）

切集时抓到的 XHR（`studyservice-api.zhihuishu.com/gateway/t/v1/`）：

```
① learning/saveDatabaseIntervalTimeV2     ← 保存上一节观看时长（进度心跳/上报）
② learning/prelearningNote                ← 学前说明（一次性）
③ course/threeDimensionalCourseWare?secretStr=XXXX&dateFormate=YYYY  ← 加载新节课件
④ popupAnswer/loadVideoPointerInfo        ← 拉新节弹题信息
```

- **`secretStr` 每次都刷新**（两次请求值不同），是**服务端下发的加密 token + 时间戳**，限时校验、**不能重放旧 URL** → 这是反篡改/反重放核心。
- `dateFormate` 是毫秒时间戳，服务端可做时间窗校验。

## 二、为什么脚本"下一集跳转"被检测 / 不支持（核心发现）

### 2.1 真凶：异常 seek 触发 Turing 滑块拼图验证码

把 4.4 **主动拖到结尾**（seek 到 `duration-3`）播放完 → 页面立刻弹出：

```
iframe (turing.captcha.gtimg.com):
  安全验证
  拖动下方滑块完成拼图
  img "feedback" / img "refresh"
```

→ 这是**腾讯 Turing 行为验证码**，**跨域 iframe，纯脚本无法稳定过**（需真实拖拽轨迹 + 缺口识别）。

**对照实验**：
- 1.1 自然播完（ct 自然到 dur=546）→ **没弹**验证码。
- 4.4 主动 seek 到结尾 → **立刻弹**验证码。

**结论**：平台把「拖进度条 / seek 跳跃」视为非人类节奏 → 触发验证码。
这正是用户说的"有的下一集会被检测为脚本，跳转不支持"——脚本想靠 seek 跳到结尾来"假装看完并 advance 下一集"，被验证码卡死。

### 2.2 切集本身（点标题）不触发验证码

点标题切集 = 加载全新 video 源、从头/断点播放、**不 seek**。实测多次切集（2.25、4.4）**均未触发验证码**。
→ 只要走"人类点标题"路线，绕过 seek，就不会踩验证码。

### 2.3 整页跳转到门户：**切集是偶发，关弹题是确定性**（round-29 更正）

这条上一轮只写了一半，第二轮真机把它彻底分清了 —— **两个不同的触发源，性质完全不同**：

| 触发源 | 性质 | 复现情况 |
|--------|------|----------|
| **切集**（点小节标题） | 偶发 / 概率性 | reload 后同样点 4.4，干净复现**未再跳**；符合累积信号型反作弊（快速连切、合成事件、无真实鼠标移动） |
| **关掉 AI 弹题的「关闭」按钮** | **确定性（稳定复现）** | 同一门课 4.4 **连测 2 次，2 次都跳**到 `https://www.zhihuishu.com/` |

所以之前"跳转是偶发"的判断**只适用于切集**；**关弹题那条是必现的**，而且因为它发生在挂机必经路径上（弹题必弹），危害比切集大得多。

**应对（已落地 v0.6.34）**：不再靠"每步后轮询 hostname"，改为调度器里的**守卫 0** —— 在学习页时记住 `location.href`；连续 3 轮读不到课程目录就自动跳回去。这一条把上面两种触发源**一起兜住**，且不会触发 SSO 掉登录（profile 保登录态）。

### 2.4 进度上报机制（决定"看完没看完"）

- 进度由 `saveDatabaseIntervalTimeV2` 按**真实观看时长**累加上报。
- 小节"已完成"以平台记录为准（DOM 标记 `.time_icofinish`），**不是**本地"视频播到结尾"——所以已完结项即使再播到结尾，`play()` 也不前进（ct===dur，ended=true）。
- 反作弊因此能区分：真看（时长累加够）→ 记完成；跳看（seek 跳段）→ 时长不够 or 触发验证码 → 不记完成。

## 三、"已看完的不需要看" + "没看完的续看" 实现依据

### 3.1 完成判据（运行时动态扫描，不要写死）

- **已完成** = `li.clearfix.video` 内含 `b.time_icofinish`（实测 53 节里 40 节有）。
- `b.time_ico_half` 是**所有项都有的进度底条**，不能当完成标志（53/53 都有）。
- ⚠️ 完成状态会变化：本次实测中 2.25 一开始未完结（index 34，firstIncomplete），因我播了一点 + 切走时 `saveDatabaseIntervalTimeV2` 上报，重扫时已带 `time_icofinish`。**所以必须每次运行时重新扫描，绝不能缓存/写死清单。**

### 3.2 未完结清单（本次快照，仅供参考，运行时以动态扫描为准）

扫描时刻未完结项（已剔除 `.time_icofinish`）：

```
第四章 线性方程组及其解空间：4.4 4.5 4.6 4.7 4.8 4.9
第五章 二次型：            5.1 5.2 5.3 5.4 5.5 5.6
```
（注意：2.25 因前述播放已可能转完结；以运行时扫描为唯一真相。）

### 3.3 续看流程（实测行为）

1. 点未完结项标题 → 页内切集，**加载到断点**（如 2.25 从 474/622 续播），**paused=true**。
2. 必须手动 `video.play()` 才继续（与关弹题后同理，见 04 文档 P1-2）。
3. 已完结项点过去会停在结尾、不前进 → 跳过。
4. 顺序：按目录 DOM 顺序（第一章→第五章），从第一个未完结项开始，逐个向后。

## 四、切集时的"温馨提示"弹窗（Edge 特有坑，必须处理）

### 4.1 现象

切到新小节（尤其跨章/首切）时，可能弹出 Element UI 的 `el-dialog`（class `el-dialog__wrapper dialog-tips`）：

```
温馨提示：为了确保学习进度的准确性，建议使用火狐浏览器或谷歌浏览器观看视频！
[我知道了]   [X]    （还有「不再提示」链接，一次性屏蔽标记）
```

- 这是**浏览器兼容性 nag**（因为我们用 Edge，不是 Chrome/火狐）。在用户真机 Chrome 上大概率不弹。
- 它是**覆盖层**，video 在背后照常播放（实测 ct 仍前进），但**视觉遮挡**。

### 4.2 处理要点（血泪）

- 关闭用 **「我知道了」按钮** 或 **X**（class `el-dialog__headerbtn`）。
- **「不再提示」只是设置永久屏蔽标记，不关当前弹窗**——还要再点「我知道了」。
- **绝对不要点「返回学堂」**！页面**顶栏常驻**一个 `返回学堂` 链接（ref 区在 dialog 之外，是页面导航），点了就跳门户、丢上下文。
- 实测：点「我知道了」后 `dialogOpen:false`，video 继续（ct 510→前进）。✅
- 该 nag **间歇性**出现（首切/跨章易触发），自动化要"每次切集后轮询并关 dialog"，不能假设一定不弹。

## 五、看不到时的备用观测手段（已验证有效）

本次多次用"无障碍树看不到"就换手段，全部奏效：

| 盲区 | 手段 | 结果 |
|------|------|------|
| 看不到 Vue 处理器（生产版无 `__vueParentComponent`） | 直接派发真实 MouseEvent 到目标元素，观察前后 DOM/URL/video 变化 | 确认点标题=页内切 |
| 看不到进度上报端点 | `eval` 里 hook `XMLHttpRequest.open` / `fetch` / `navigator.sendBeacon` | 抓到 `saveDatabaseIntervalTimeV2` 等 4 个 API |
| 看不到跳转原因 | 装"导航陷阱"：重写 `location.assign/replace`、`window.open`、`history.pushState/replaceState`、document capture 阶段拦截 `<a>` 点击并 preventDefault | 复现时跳转被拦截、会话不破 |
| 看不到跳转时机 | 单轮 `eval` 内 `setInterval` 每 300ms 记录 `location.href` + dialog + ct，一次性返回时间线 | 精确定位"seek→验证码"触发点 |
| 验证码在跨域 iframe | 无障碍树能列出 iframe 内"安全验证/拖动下方滑块完成拼图"文本（Playwright 把跨域 iframe 内容也纳入 a11y 树） | 确认验证码类型与文案 |

→ 结论：**没有真正的盲区**，a11y 树 + eval 深度 dump + 运行时 hook/陷阱 三层覆盖足够。

## 六、给自动化的硬约束（设计输入）

1. **切集只点 `span.catalogue_title`**（内部标题），**绝不**点 `li` 本身、绝不 `li.click()`、绝不 seek。
2. **切集后轮询关闭「温馨提示」**：命中 `.el-dialog__wrapper.dialog-tips` → 点「我知道了」；**严禁点「返回学堂」**。
3. **切集/关弹题后强制 `video.play()`** 并轮询 `paused===false`；paused 且非验证码挡 → 再 play 一次。
4. **跳过已完成**：点目标前先判 `.time_icofinish`；含则跳下一未完结项。**每次运行时重扫清单**。
5. **绝不 seek**：只自然播放或点标题切集，从根上规避 Turing 验证码。
6. **导航守卫**：每步后查 `location.hostname`；非 `studyvideoh5` 立即 `goto` 课程 URL 恢复。
7. **验证码兜底**：检测到 Turing iframe 变可见/阻塞 → 暂停流程 + 高亮提示人工过码 → 过完 `play()`。不自动破解。
8. **节奏防御**：弹题关闭加 0.5~1.5s 随机延迟；倍速 ≤1.5x；窗口可见不可最小化。
