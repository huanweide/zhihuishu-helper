# 使用说明（v0.1.0）

> 面向使用者的完整操作手册。装完之后怎么用、面板每个按钮干什么、出问题怎么看，都在这里。

---

## 一、安装（3 步）

### 1. 装 Tampermonkey

浏览器扩展商店搜 **Tampermonkey**（油猴），或者去官网 <https://www.tampermonkey.net/> 装。

Chrome / Edge / Firefox 都支持。

### 2. 装脚本

1. 打开 Tampermonkey 面板 → **添加新脚本**
2. 把 `dist/zhihuishu-helper.user.js` 的内容**全选复制**过去
3. `Ctrl+S` 保存

> 更省事的做法：Tampermonkey → 实用工具 → 从文件导入，选那个 `.user.js` 文件。

### 3. 确认生效

打开智慧树课程页，右下角出现**蓝色圆形「智」按钮**就算成功。点它展开面板。

---

## 二、第一次使用（重要）

### 步骤 1：开自动播放

面板默认就是开着的（自动播放 / 自动下一节 / 静音 / 断点续播 都是绿色）。

### 步骤 2：配 AI 答题（可选）

要自动答题得先配 **LLM Key**：

1. 面板 → **设置** 页
2. 找到 **LLM Key**，填你的 API Key（DeepSeek 的填 `sk-` 开头那串）
3. 回到 **状态** 页，把 **AI 自动答题** 开关打开

**LLM 默认走 DeepSeek**（`https://api.deepseek.com`），任何 OpenAI 兼容接口都能用。

### 步骤 3：配题库（可选但强烈推荐）

题库比 LLM 快得多也准得多。装 [tikuAdapter](https://github.com/DokiDoki1103/tikuAdapter)
本地跑起来（默认 `http://localhost:8060`），面板里 **题库地址** 填上去就行，不用改。

题库没命中会自动降级到 LLM。

## 三、面板说明

### 状态页

| 字段 | 含义 |
|------|------|
| 运行状态 | 运行中 / 已停止 |
| 页面版本 | 识别到的页面族（wisdom / fusion / hike / legacy / card2025） |
| 当前课时 | 正在播放的章节名 |
| 视频进度 | 当前百分比 · 已播秒数 |
| 课程完成 | 已完成章节数 / 总章节数（百分比） |
| 已答题数 | 本次运行累计作答数 |
| 本次运行 | 脚本运行了多久 |

### 日志页

实时滚动日志。出问题第一时间看这里。带颜色的：
- 黄色 = 警告（比如检测到安全验证）
- 红色 = 错误

### 设置页

| 开关 | 默认 | 说明 |
|------|------|------|
| 自动播放 | 开 | 关掉就完全不动视频 |
| 自动下一节 | 开 | 一节放完自动切下一个未完成章节 |
| 静音 | 开 | `volume=0`，必须静音才能绕过浏览器自动播放策略 |
| 断点续播 | 开 | 关掉不记录也不恢复 |
| AI 自动答题 | **关** | 需要配 Key 才建议开 |
| 题库通道 | 开 | 优先查题库 |
| LLM 通道 | 开 | 题库没命中才用 |
| 调试日志 | 开 | 关掉减少控制台输出 |

| 控件 | 说明 |
|------|------|
| 答题模式 | 双通道 / 仅题库 / 仅LLM |
| 倍速 | 滑条 1.0 ~ 1.8，**超过 1.8 会被平台判定异常，别调** |
| 题库地址 | 默认 `http://localhost:8060` |
| LLM Key | 填了才走 LLM 通道 |
| 投票次数 | LLM 生成几次取众数，默认 3。题多就调 1 加快 |

### 底部按钮

| 按钮 | 作用 |
|------|------|
| 启动 | 开始主循环 |
| 停止 | 停下所有自动化动作 |
| 下一节 | 手动跳到下一个未完成章节 |
| 答题 | 手动触发一次答题（自动识别当前是弹题还是作业页） |

## 四、控制台 API（进阶）

按 `F12` 打开控制台，可以用这些：

```js
zhs.stats()               // 课程完成统计
zhs.logs()                // 全部日志（数组）
zhs.start()               // 启动
zhs.stop()                // 停止
zhs.next()                // 切下一节
zhs.clearResume()         // 清除本课程的续播记录
zhs.config({ speed: 1.5 })// 改配置
window.ZHS.Resume.list()  // 看所有续播记录
window.ZHS.Solver.stats   // 看答题统计（题库命中几次、LLM 几次）
window.ZHS.Bank.ping()    // 测题库连通性
window.ZHS.LLM.test()     // 测 LLM 连通性
```

## 五、已知限制与注意事项

### ⚠️ 浏览器可以缩小，但**不要最小化**

浏览器对**不可见标签页**会把定时器节流到 1 次/分钟，视频回调和脚本主循环都会被冻住。
想干别的就**把窗口缩小放一边**，别点最小化。

### 倍速上限 1.8

不是脚本保守，是平台机制：平台用 `timeupdate` 事件采样上报进度，
倍速太高时采样点跳变太大，后端校验判定为异常播放，**学时直接不记**。
所以硬夹在 1.8。

### 验证码需要你手动过

检测到易盾滑块之类的安全验证，脚本会**自动暂停**并在面板弹提示。
你手动滑完，脚本会自动继续 —— 这是设计如此，不是故障。

### 图片题会跳过

题干或选项是图片的题，目前识别到会跳过（OCR 未实现）。

### 仅限个人学习研究

不要拿去商用或传播。用这个脚本属于你自己承担风险的行为。

## 六、出问题怎么排查

**顺序：面板 → 日志页 → 控制台**

### 脚本没反应

1. 面板右下角「智」按钮在不在？不在 → 脚本没生效，检查 Tampermonkey 里脚本是否启用、页面是否匹配
2. 在的话点开，看 **日志页** 最后几行

### 不自动播放

1. 状态页「页面版本」是不是 `未识别`？是的话说明页面结构变了，需要更新选择器
2. 看日志有没有 `检测到安全验证` —— 有的话是你需要手动过验证码
3. 检查「自动播放」开关

### 不自动答题

1. 「AI 自动答题」开关开了吗？（默认是关的）
2. LLM Key 配了吗？控制台跑 `await window.ZHS.LLM.test()` 看返回
3. 题库地址通不通？控制台跑 `await window.ZHS.Bank.ping()`
4. 看日志有没有 `题库未命中` / `LLM 请求失败`

### 断点续播不生效

1. 「断点续播」开关
2. 控制台跑 `window.ZHS.Resume.list()` 看有没有记录
3. 没有记录 → 看日志有没有写入失败告警
4. 有记录但不恢复 → 检查记录里的课时名是否还存在（课时被老师改过名字会找不到）

### 进度不记 / 学时没拿到

1. 倍速是不是调太高了？回到 1.5 试试
2. 视频窗口是不是被最小化了？
3. 日志里有没有 `视频已结束但平台仅记录 X%，回退重试`

---

## 七、卸载

Tampermonkey 面板里删掉脚本即可。

想清掉续播记录：控制台跑 `window.ZHS.Resume.clearAll()`。
